## Module 1 — Probability distributions

> **In short:** a **random variable** turns the outcome of an experiment into a number. A **probability distribution** says how likely each value is: a **mass function** for discrete variables, a **density function** for continuous ones. Learn the mean and variance of each, and four standard distributions: **binomial**, **Poisson**, **normal** and **exponential**.

```flow
Identify the random variable -> Discrete or continuous? -> Choose distribution (binomial, Poisson, normal, exponential) -> Write P(X) -> Compute the probability, mean and variance
```

### Review of basic probability

- **Sample space S:** all possible outcomes. **Event:** a subset of S.
- **Classical probability:** P(A) = (favourable outcomes) / (total outcomes), when all outcomes are equally likely.
- **Axioms:** 0 ≤ P(A) ≤ 1; P(S) = 1; for mutually exclusive events, P(A ∪ B) = P(A) + P(B).
- **Addition rule:** P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
- **Conditional probability:** P(A | B) = P(A ∩ B) / P(B).
- **Independent events:** P(A ∩ B) = P(A) P(B).

### Random variables

A **random variable (RV)** X assigns a real number to each outcome.

- **Discrete RV:** takes countable values (number of defective items).
- **Continuous RV:** takes any value in an interval (time, height).

### Probability mass and density functions

**Discrete: probability mass function (PMF)** p(x) = P(X = x), with:

- p(x) ≥ 0 for every x
- Σ p(x) = 1

**Continuous: probability density function (PDF)** f(x), with:

- f(x) ≥ 0
- ∫ f(x) dx over all x = 1
- P(a ≤ X ≤ b) = ∫ from a to b of f(x) dx. For a continuous RV, P(X = a) = 0.

**Cumulative distribution function (CDF):** F(x) = P(X ≤ x).

### Mathematical expectation, mean and variance

| | Discrete | Continuous |
|---|---|---|
| Mean μ = E(X) | Σ x p(x) | ∫ x f(x) dx |
| E(X²) | Σ x² p(x) | ∫ x² f(x) dx |
| Variance σ² = V(X) | E(X²) − μ² | E(X²) − μ² |

Standard deviation σ = √V(X).

**Worked example:** X takes values 0, 1, 2 with probabilities 0.2, 0.5, 0.3. Mean = 0 + 0.5 + 0.6 = 1.1. E(X²) = 0 + 0.5 + 1.2 = 1.7. Variance = 1.7 − 1.21 = 0.49, so σ = 0.7.

**Finding an unknown constant k:** set Σ p(x) = 1 (discrete) or ∫ f(x) dx = 1 (continuous), and solve for k.

### Binomial distribution

Use it for **n independent trials**, each with **two outcomes** (success with probability p, failure with q = 1 − p), counting the number of successes X.

- **P(X = x) = ⁿCₓ pˣ qⁿ⁻ˣ**, for x = 0, 1, …, n
- **Mean = np**, **Variance = npq**, SD = √(npq)

**Derivation of the mean (outline):** E(X) = Σ x ⁿCₓ pˣ qⁿ⁻ˣ. Using x ⁿCₓ = n ⁿ⁻¹Cₓ₋₁, this becomes np Σ ⁿ⁻¹Cₓ₋₁ pˣ⁻¹ qⁿ⁻ˣ = np (p + q)ⁿ⁻¹ = np. The variance uses E[X(X − 1)] = n(n − 1)p², so V(X) = n(n − 1)p² + np − n²p² = npq.

**Worked example:** a coin is tossed 6 times. P(exactly 4 heads) = ⁶C₄ (1/2)⁴ (1/2)² = 15/64 ≈ 0.234.

### Poisson distribution

Use it for the **number of events in a fixed interval** when events are rare and independent (calls per minute, defects per sheet). It is the limit of the binomial when n is large, p small and np = m stays fixed.

- **P(X = x) = e⁻ᵐ mˣ / x!**, for x = 0, 1, 2, …
- **Mean = m**, **Variance = m** (mean and variance are equal)

**Worked example:** a page has on average 2 typing errors (m = 2). P(no errors) = e⁻² ≈ 0.135. P(at least one) = 1 − 0.135 = 0.865.

### Normal distribution

The bell-shaped, continuous distribution with mean μ and standard deviation σ:

f(x) = (1 / (σ√(2π))) e^(−(x − μ)² / (2σ²))

- Symmetric about μ; mean = median = mode.
- About **68%** of values lie within μ ± σ, **95%** within μ ± 2σ, **99.7%** within μ ± 3σ.
- **Standard normal variable:** z = (x − μ) / σ has mean 0 and SD 1. Use the **z-table** (area from 0 to z) to find probabilities.

**Worked example:** marks are normal with μ = 60, σ = 10. P(X > 75): z = (75 − 60)/10 = 1.5. Area from 0 to 1.5 is 0.4332, so P = 0.5 − 0.4332 = 0.0668 (about 6.7% of students).

### Exponential distribution

Models the **waiting time** between Poisson events (time until the next call, life of a component).

- **f(x) = α e^(−αx)** for x ≥ 0 (α > 0)
- **Mean = 1/α**, **Variance = 1/α²**
- P(X > a) = e^(−αa)
- **Memoryless property:** P(X > s + t | X > s) = P(X > t).

## Module 2 — Joint probability distributions and Markov chains

> **In short:** a **joint distribution** gives the probabilities for two random variables together. From it we get each variable's **marginal** distribution, check **independence**, and measure how they vary together with **covariance** and **correlation**. A **Markov chain** is a process where the next state depends only on the current state, described by a **transition matrix**.

```flow
Joint table P(x, y) -> Marginals f(x), g(y) -> E(X), E(Y), E(XY) -> Cov(X, Y) = E(XY) − E(X)E(Y) -> Correlation ρ = Cov / (σx σy)
```

### Joint probability distribution for two discrete random variables

The **joint PMF** J(x, y) = P(X = x, Y = y), usually written as a table, with every entry ≥ 0 and the total = 1.

- **Marginal distribution of X:** f(x) = Σ over y of J(x, y) (row sums).
- **Marginal distribution of Y:** g(y) = Σ over x of J(x, y) (column sums).
- **Independence:** X and Y are independent if J(x, y) = f(x) g(y) for **every** pair.

### Expectation, covariance and correlation

- E(X) = Σ x f(x); E(Y) = Σ y g(y)
- **E(XY) = Σ Σ x y J(x, y)**
- **Covariance:** Cov(X, Y) = E(XY) − E(X) E(Y)
- **Correlation:** ρ(X, Y) = Cov(X, Y) / (σₓ σᵧ), between −1 and 1.
- If X and Y are independent, Cov(X, Y) = 0 (but zero covariance does not always mean independence).

**Worked example:**

| | Y = 0 | Y = 1 | f(x) |
|---|---|---|---|
| X = 0 | 0.2 | 0.1 | 0.3 |
| X = 1 | 0.3 | 0.4 | 0.7 |
| g(y) | 0.5 | 0.5 | 1 |

E(X) = 0.7, E(Y) = 0.5, E(XY) = 1 × 1 × 0.4 = 0.4. Cov = 0.4 − 0.35 = 0.05. Since J(0, 0) = 0.2 but f(0) g(0) = 0.15, X and Y are **not independent**.

### Stochastic processes and probability vectors

- A **stochastic process** is a family of random variables indexed by time, {Xₜ}.
- A **probability vector** has non-negative entries that add up to 1, for example (0.3, 0.7).

### Stochastic and regular stochastic matrices

- A **stochastic (transition) matrix** is a square matrix whose **every row is a probability vector**.
- A stochastic matrix P is **regular** if some power Pⁿ has **all entries positive**.

### Markov chains

A **Markov chain** is a stochastic process where the probability of the next state depends **only on the present state** (the Markov property).

- **Transition probability** pᵢⱼ = P(next state is j | current state is i).
- The **transition matrix** P = [pᵢⱼ] is stochastic.
- If p⁽⁰⁾ is the initial probability vector, the distribution after n steps is **p⁽ⁿ⁾ = p⁽⁰⁾ Pⁿ**.

### Higher transition probabilities

The **n-step transition matrix** is **Pⁿ**: its (i, j) entry is the probability of going from i to j in exactly n steps.

**Worked example:** a student's habit: if they study today, they study tomorrow with probability 0.7; if not, they study tomorrow with probability 0.4.

P = [[0.7, 0.3], [0.4, 0.6]] (states: study, not study)

P² = [[0.7×0.7 + 0.3×0.4, 0.7×0.3 + 0.3×0.6], [0.4×0.7 + 0.6×0.4, 0.4×0.3 + 0.6×0.6]] = [[0.61, 0.39], [0.52, 0.48]]

So if the student studies today, the probability they study two days from now is 0.61.

### Stationary distribution of regular Markov chains and absorbing states

For a **regular** chain, there is a unique **stationary (fixed) probability vector** v with **vP = v** and entries adding to 1. In the long run, p⁽ⁿ⁾ approaches v whatever the starting state.

**Worked example (same chain):** v = (a, b) with a + b = 1 and 0.7a + 0.4b = a. So 0.4b = 0.3a, giving a = 4/7 and b = 3/7. In the long run the student studies on 4/7 of days.

- **Absorbing state:** a state that cannot be left (pᵢᵢ = 1). A chain with an absorbing state is not regular.

## Module 3 — Statistical inference (1): sampling and large-sample tests

> **In short:** we study a **sample** to learn about a **population**. A **sampling distribution** describes how a statistic (like the sample mean) varies from sample to sample; its standard deviation is the **standard error**. **Hypothesis testing** decides whether data supports a claim, by comparing a test statistic with a critical value at a chosen **level of significance**.

```flow
State H0 and H1 -> Choose significance level (5% or 1%) -> Compute test statistic z -> Compare |z| with critical value -> |z| > critical? Reject H0 -> Else do not reject H0
```

### Sampling distribution and standard error

- **Population:** the whole group; its values are **parameters** (μ, σ, P).
- **Sample:** a part of the population; its values are **statistics** (x̄, s, p).
- **Sampling distribution:** the distribution of a statistic over all possible samples of the same size.
- **Standard error (SE):** the standard deviation of a sampling distribution.
  - SE of the sample mean = σ / √n
  - SE of a sample proportion = √(PQ / n)

### Testing of hypothesis

- **Null hypothesis H₀:** the claim of "no difference" being tested (for example, μ = 50).
- **Alternative hypothesis H₁:** what we accept if H₀ is rejected (μ ≠ 50, two-tailed; μ > 50 or μ < 50, one-tailed).
- **Errors:**
  - **Type I error:** rejecting H₀ when it is true. Its probability is the level of significance α.
  - **Type II error:** accepting H₀ when it is false. Its probability is β.

### Levels of significance and critical values

The **level of significance** α is the risk of a Type I error we accept, usually 5% or 1%.

| Level | Two-tailed critical z | One-tailed critical z |
|---|---|---|
| 5% | 1.96 | 1.645 |
| 1% | 2.58 | 2.33 |

### Tests of significance and confidence limits

**Test of significance:** compute z = (statistic − parameter) / SE. If |z| is greater than the critical value, the difference is **significant** and H₀ is rejected.

**Confidence limits** for a parameter: statistic ± (critical z) × SE.

- 95% confidence limits for μ: x̄ ± 1.96 σ/√n
- 99% confidence limits for μ: x̄ ± 2.58 σ/√n

### Simple sampling of attributes

Sampling of **attributes** counts how many items have a quality (defective or not), so each draw is a success or failure.

- For n draws with success probability p: expected number of successes = np, SD = √(npq).
- **Test for the number of successes:** z = (x − np) / √(npq).
- **Test for a proportion:** z = (p̂ − P) / √(PQ/n), where p̂ is the sample proportion.

**Worked example:** a coin is tossed 400 times and shows 216 heads. Is it fair? H₀: p = 0.5. Expected = 200, SD = √(400 × 0.5 × 0.5) = 10. z = (216 − 200)/10 = 1.6 < 1.96, so at the 5% level the difference is not significant: the coin may be fair.

### Test of significance for large samples

For **large samples** (n > 30), the sampling distribution is approximately normal, so we use z.

**Test for a single mean:** z = (x̄ − μ) / (σ/√n). If σ is unknown, use the sample SD s.

**Worked example:** a sample of 100 has mean 52 and SD 10. Test whether μ = 50 at 5%. z = (52 − 50) / (10/√100) = 2/1 = 2 > 1.96, so reject H₀: the mean differs significantly from 50.

### Comparison of large samples

**Difference of two means:**

z = (x̄₁ − x̄₂) / √(σ₁²/n₁ + σ₂²/n₂)

**Difference of two proportions:**

z = (p₁ − p₂) / √(PQ (1/n₁ + 1/n₂)), where P = (n₁p₁ + n₂p₂)/(n₁ + n₂) is the pooled proportion and Q = 1 − P.

## Module 4 — Statistical inference (2): small samples, t, chi-square and F

> **In short:** the **central limit theorem** says sample means are approximately normal for large n. For **small samples** (n ≤ 30) with unknown σ, use **Student's t** distribution. The **chi-square (χ²)** test checks how well observed frequencies fit expected ones. The **F** distribution compares two variances.

```flow
Small sample, test a mean -> Student's t with n − 1 degrees of freedom
Observed vs expected frequencies -> Chi-square goodness of fit
Compare two variances -> F-test
```

### Sampling variables and the central limit theorem

- **Central limit theorem (CLT):** if samples of size n are drawn from **any** population with mean μ and SD σ, then for large n the sample mean x̄ is approximately **normal** with mean μ and SD σ/√n.
- **Confidence limits for an unknown mean** (large samples): x̄ ± z (σ/√n), using s for σ if unknown.

### Student's t-distribution

For a small sample (n ≤ 30) from a normal population with unknown σ:

**t = (x̄ − μ) / (s/√n)**, with **ν = n − 1 degrees of freedom**, where s² = Σ (x − x̄)² / (n − 1).

- The t-curve is symmetric and bell-shaped but has heavier tails than the normal curve; as ν grows it approaches the normal.
- Compare |t| with the table value t(α, ν).

**Worked example:** a sample of 10 bolts has mean length 4.8 cm and s = 0.3 cm. Test μ = 5 cm at 5%. t = (4.8 − 5) / (0.3/√10) = −0.2/0.0949 ≈ −2.11. For ν = 9, the two-tailed 5% value is 2.262. Since 2.11 < 2.262, do not reject H₀.

### Test of significance for the means of two small samples

**t = (x̄ − ȳ) / (S √(1/n₁ + 1/n₂))**, with ν = n₁ + n₂ − 2, where the pooled variance is

S² = [Σ (x − x̄)² + Σ (y − ȳ)²] / (n₁ + n₂ − 2).

This assumes both populations are normal with equal variances.

### Chi-square distribution as a test of goodness of fit

**χ² = Σ (O − E)² / E**, where O are observed and E expected frequencies.

- **Degrees of freedom** ν = (number of classes) − 1 − (number of parameters estimated from the data).
- If χ² (calculated) < χ² (table) at the chosen level, the fit is **good**: accept H₀.
- Conditions: total frequency large (at least 50), each expected frequency at least 5 (merge small classes).

**Worked example:** a die is thrown 60 times: faces 1–6 appear 8, 12, 9, 11, 7, 13 times. Expected = 10 each. χ² = (4 + 4 + 1 + 1 + 9 + 9) / 10 = 2.8. For ν = 5, the 5% table value is 11.07. Since 2.8 < 11.07, the die appears fair.

### F-distribution

Used to **compare two population variances** (and in ANOVA).

**F = s₁² / s₂²** (the larger estimate on top), with (n₁ − 1, n₂ − 1) degrees of freedom, where s² = Σ (x − x̄)² / (n − 1).

If F (calculated) < F (table) at the chosen level, the variances are not significantly different.

## Module 5 — Design of experiments and ANOVA

> **In short:** **design of experiments** plans how to collect data so that differences between **treatments** can be tested fairly. **ANOVA (analysis of variance)** splits the total variation into parts due to treatments and due to chance, and uses an **F-test** to decide whether the treatment means differ. Designs: **completely randomised**, **randomised block** and **Latin square**.

```flow
Total sum of squares -> Split into treatment SS (between groups) and error SS (within groups) -> Mean squares = SS / df -> F = MS treatment / MS error -> Compare with F table
```

### Principles of experimentation in design

1. **Randomisation:** assign treatments to experimental units at random, to avoid bias.
2. **Replication:** repeat each treatment several times, to estimate the experimental error.
3. **Local control (blocking):** group similar units into blocks, to reduce error.

### The ANOVA technique and its basic principle

ANOVA tests whether **several means are equal** (H₀: μ₁ = μ₂ = … = μₖ). The idea: if the variation **between** groups is large compared with the variation **within** groups, the means differ.

**Assumptions:** the observations are independent, each population is normal, and the populations have equal variances.

### One-way ANOVA (completely randomised design)

k treatments, N observations in total, T = grand total.

- **Correction factor:** CF = T² / N
- **Total SS** = Σ x² − CF
- **Treatment (between) SS** = Σ (Tᵢ² / nᵢ) − CF, where Tᵢ is the total of treatment i
- **Error (within) SS** = Total SS − Treatment SS

**ANOVA table:**

| Source | SS | df | MS | F |
|---|---|---|---|---|
| Between treatments | SST | k − 1 | MST = SST/(k − 1) | MST / MSE |
| Error | SSE | N − k | MSE = SSE/(N − k) | |
| Total | | N − 1 | | |

If F (calculated) > F (table) at the chosen level, reject H₀: the treatments differ.

### Randomised block design and two-way ANOVA

In a **randomised block design (RBD)**, units are grouped into **blocks**, and each treatment appears once in every block in random order. This removes block-to-block variation.

**Two-way ANOVA** (k treatments in columns, r blocks in rows, one observation per cell):

- Column (treatment) SS = Σ (column totals²)/r − CF
- Row (block) SS = Σ (row totals²)/k − CF
- Error SS = Total SS − column SS − row SS

| Source | df |
|---|---|
| Treatments (columns) | k − 1 |
| Blocks (rows) | r − 1 |
| Error | (k − 1)(r − 1) |
| Total | kr − 1 |

Two F-ratios are formed: treatments MS / error MS and blocks MS / error MS.

### Latin-square design

Controls variation in **two directions** (rows and columns). With m treatments, the design is an **m × m square** in which each treatment appears **exactly once in each row and each column**.

- Sources of variation: rows, columns, treatments, error.
- Degrees of freedom: rows m − 1, columns m − 1, treatments m − 1, error (m − 1)(m − 2), total m² − 1.

### Analysis of covariance (ANCOVA)

**ANCOVA** combines ANOVA with regression. It adjusts the response for the effect of a **covariate** (an extra variable that cannot be controlled, such as students' previous marks) before comparing treatment means. This reduces error and gives a fairer comparison.

## Exam tips

- **Numericals carry nearly all the marks:** binomial, Poisson and normal probabilities; finding k and the mean and variance of a distribution; a joint distribution table with covariance and correlation; a Markov chain's Pⁿ and stationary vector; z, t, χ² and F tests; and a one-way or two-way ANOVA table.
- **Write the hypotheses (H₀, H₁)**, the formula, the degrees of freedom, the table value and the conclusion in words for every test.
- Learn the **critical values** (1.96, 2.58, 1.645) and how to read t, χ² and F tables.
- Know the **derivations** of the mean and variance of the binomial and Poisson distributions; they are named in the syllabus.
- Keep at least four decimal places in intermediate steps to avoid rounding errors.
