## Module 1 — Introduction and understanding data (1)

> **In short:** **machine learning (ML)** lets a computer learn patterns from **data** instead of being given explicit rules. There are three main types: **supervised** (learn from labelled examples), **unsupervised** (find structure in unlabelled data) and **reinforcement** learning (learn by reward). Before any learning, you must understand the data with **descriptive statistics** and **plots**.

```flow
Understand the business problem -> Understand the data -> Prepare the data -> Build the model -> Evaluate -> Deploy
```

### Need for machine learning

- Organisations collect huge amounts of data, but data is useless until it is turned into **knowledge** and decisions.
- Some tasks are too complex to program by hand (recognising faces, filtering spam). ML learns them from examples.
- The **knowledge pyramid**: data → information → knowledge → intelligence → wisdom. ML helps climb from data to knowledge.

### Machine learning explained

**Tom Mitchell's definition:** a program learns from **experience E** with respect to a **task T** and a **performance measure P**, if its performance at T, measured by P, improves with E.

Example (spam filter): T = classify emails as spam or not; E = a set of labelled emails; P = the percentage of emails classified correctly.

In conventional programming, **data + program → output**. In ML, **data + output → program (model)**.

### Machine learning in relation to other fields

| Field | Relation to ML |
|---|---|
| Artificial intelligence | ML is a branch of AI; deep learning is a branch of ML |
| Data science | Uses ML as one of its main tools, along with data collection and visualisation |
| Data mining | Finds hidden patterns in large data; shares many algorithms with ML |
| Statistics | Supplies the mathematical foundation; statistics focuses on models and inference, ML on prediction |
| Big data | Supplies the volume of data that ML needs |

### Types of machine learning

- **Supervised learning:** training data has inputs and correct outputs (**labels**).
  - **Classification:** the output is a category (spam / not spam).
  - **Regression:** the output is a number (house price).
- **Unsupervised learning:** no labels; find structure.
  - **Clustering:** group similar items (customer segments).
  - **Dimensionality reduction:** compress many features into few.
  - **Association rules:** items that occur together (market-basket analysis).
- **Semi-supervised learning:** a small labelled set plus a large unlabelled set.
- **Reinforcement learning:** an **agent** acts in an **environment** and learns from **rewards** and penalties (game playing, robots).

### Challenges of machine learning

- **Data quality:** missing, noisy or inconsistent data.
- **Problems that are not well-posed** (ill-posed): the data does not determine a unique answer.
- **Huge data and high computing cost.**
- **Overfitting** (the model memorises training data and fails on new data) and **underfitting** (the model is too simple).
- **Bias–variance trade-off**, choosing the right algorithm, and explaining the model's decisions.

### The machine learning process

The **CRISP-DM** process:

1. **Understanding the business:** what problem, what goal?
2. **Understanding the data:** collect it, explore it, check its quality.
3. **Preparation of data:** clean it, handle missing values, transform features.
4. **Modelling:** choose and train algorithms.
5. **Evaluate:** test on unseen data with suitable measures.
6. **Deployment:** put the model into use and monitor it.

### Machine learning applications

Sentiment analysis, recommendation systems, voice assistants, spam filtering, fraud detection, medical diagnosis, self-driving cars, image and face recognition, stock-market prediction.

### Understanding data: types and the big data framework

**Big data** is described by the **Vs**: **volume** (size), **velocity** (speed of arrival), **variety** (forms), **veracity** (trustworthiness), **validity**, **value**.

**Types of data:**

- **Structured** (tables), **unstructured** (text, images, video) and **semi-structured** (XML, JSON).
- **Categorical (qualitative):**
  - **Nominal:** names with no order (blood group).
  - **Ordinal:** an order but unequal gaps (grades A, B, C).
- **Numerical (quantitative):**
  - **Interval:** equal gaps but no true zero (temperature in °C).
  - **Ratio:** equal gaps and a true zero (height, salary).
- Also **discrete** (counts) versus **continuous** (measurements).

**Big data analysis framework (layers):** data connection layer (ingest data), data management layer (store and preprocess), data analytics layer (statistics and ML), presentation layer (dashboards, reports).

**Data preprocessing:**

- **Missing values:** ignore the record, fill with a constant, the mean or median, or a predicted value.
- **Noise and outliers:** binning (smoothing by bin means or boundaries), regression.
- **Normalisation:** min–max scaling v′ = (v − min) / (max − min); **z-score** v′ = (v − mean) / standard deviation.

### Descriptive statistics

Describes the main features of data without drawing conclusions about a larger population.

**Central tendency:**

- **Mean** = sum ÷ count. Sensitive to outliers. (Also weighted, geometric and harmonic means.)
- **Median:** the middle value of the sorted data. Robust to outliers.
- **Mode:** the most frequent value.

**Dispersion (spread):**

- **Range** = max − min.
- **Quartiles:** Q1 (25th percentile), Q2 (median), Q3 (75th). **Interquartile range IQR = Q3 − Q1.**
- **Variance** σ² = Σ(x − mean)² / n, and **standard deviation** σ = √variance.
- **Five-number summary:** min, Q1, median, Q3, max.

**Shape:**

- **Skewness:** asymmetry. Positive skew has a long right tail (mean > median).
- **Kurtosis:** how heavy the tails are compared with a normal distribution.

**Worked example:** data 2, 4, 4, 5, 7, 8, 10. Mean = 40/7 ≈ 5.71; median = 5; mode = 4; range = 8.

### Univariate data analysis and visualisation

**Univariate** analysis looks at one variable at a time.

- **Bar chart:** frequencies of categories.
- **Pie chart:** each category's share of the whole.
- **Histogram:** frequency of numeric values in ranges (bins); shows the shape of the distribution.
- **Dot plot:** each value as a dot.
- **Box plot (box-and-whisker):** draws the five-number summary; points beyond 1.5 × IQR from the box are shown as **outliers**.
- **Stem-and-leaf plot**, and checks of the **probability distribution** (normal, uniform).

## Module 2 — Understanding data (2) and basic learning theory

> **In short:** real data has many variables. **Bivariate** and **multivariate** analysis study how variables relate (covariance, correlation, scatter plots). **Feature engineering** and **dimensionality reduction** (such as **PCA**) keep the useful information in fewer features. Learning theory explains how to **design a learning system** and how a model searches for the right **hypothesis**.

```flow
Raw features -> Feature selection or extraction -> Fewer, better features -> Train model
Choose training experience -> Choose target function -> Choose representation -> Choose learning algorithm -> Final design
```

### Bivariate data

Two variables studied together, for example temperature and ice-cream sales.

- **Scatter plot:** one variable on each axis; shows the relationship.
- **Line graph:** a variable over time.
- **Covariance:** cov(x, y) = Σ (xᵢ − x̄)(yᵢ − ȳ) / n. Positive means they rise together; its size depends on the units.
- **Correlation (Pearson's r):** r = cov(x, y) / (σₓ σᵧ), between −1 and +1. It measures linear relationship only; **correlation is not causation**.

### Multivariate data and statistics

**Multivariate** data has three or more variables.

- **Mean vector:** the mean of each variable.
- **Covariance matrix:** the covariance of every pair of variables (variances on the diagonal).
- **Correlation matrix** and **heatmap** to see which variables move together.
- **Pair plot (scatter matrix):** a scatter plot for every pair of variables.
- Multivariate methods include **regression**, **factor analysis** and **multivariate analysis of variance (MANOVA)**.

### Essential mathematics for multivariate data

- **Linear algebra:** vectors, matrices, matrix multiplication, transpose, inverse; solving linear systems (Gaussian elimination); **matrix decomposition**, **eigenvalues and eigenvectors** (Av = λv).
- **Probability:** probability distributions, joint and conditional probability.
- **Information theory:** **entropy** H = −Σ pᵢ log₂ pᵢ measures uncertainty; it is used in decision trees.

### Feature engineering

- **Feature transformation:** create new features from existing ones (feature construction) or extract compact ones (feature extraction).
- **Feature subset selection:** keep only relevant, non-redundant features.
  - **Filter methods:** rank features by a statistic (correlation, information gain), independent of the model.
  - **Wrapper methods:** try subsets with the actual model and keep the best (forward selection, backward elimination).
  - **Embedded methods:** the model selects features while it trains (such as decision trees).

### Dimensionality reduction

Too many features cause the **curse of dimensionality**: data becomes sparse and models overfit.

**Principal Component Analysis (PCA):**

1. Standardise the data (subtract the mean of each variable).
2. Compute the **covariance matrix**.
3. Find its **eigenvalues and eigenvectors**.
4. Sort the eigenvectors by eigenvalue, largest first. These are the **principal components**: new, uncorrelated directions of greatest variance.
5. Keep the top k components and project the data onto them.

The proportion of variance kept = (sum of the k largest eigenvalues) ÷ (sum of all eigenvalues).

Other techniques: **Linear Discriminant Analysis (LDA)**, which finds directions that best separate classes, and **Singular Value Decomposition (SVD)**.

### Design of a learning system

Example: a program that learns to play checkers.

1. **Choose the training experience:** direct (labelled board positions) or indirect (game outcomes); the learner controls the examples or not; how well the training matches the real test.
2. **Choose the target function:** what exactly to learn, for example V(board) = the value of a board position.
3. **Choose a representation** of the target function, for example a linear combination of board features: V(b) = w₀ + w₁x₁ + … + wₙxₙ.
4. **Choose a learning algorithm** to adjust the weights, for example the **LMS (least mean squares)** rule: wᵢ ← wᵢ + η (V_train(b) − V(b)) xᵢ.

### Introduction to concept learning

**Concept learning** infers a Boolean function (is it an example of the concept or not?) from training examples.

- A **hypothesis** h is a candidate description of the concept, usually a conjunction of attribute constraints.
- Notation: "?" accepts any value, "Ø" accepts no value, a specific value accepts only that value.
- The **hypothesis space** H is all hypotheses the learner considers.
- Hypotheses are ordered from **general** to **specific**.

**Find-S algorithm (find the most specific hypothesis):**

```flow
Start with h = most specific (Ø, Ø, …) -> For each positive example, generalise h just enough to cover it -> Ignore negative examples -> Output h
```

Find-S ignores negative examples and finds only one hypothesis.

**List-Then-Eliminate** and **Candidate Elimination** keep the **version space**: all hypotheses consistent with the training data.

- The **specific boundary S** is generalised by positive examples.
- The **general boundary G** is specialised by negative examples.
- The version space lies between S and G.

### Modelling in machine learning

- **Training set** to fit the model, **test set** to measure it, and often a **validation set** to tune it.
- **Cross-validation (k-fold):** split the data into k parts; train on k − 1 and test on the remaining one, k times; average the results.
- **Bias–variance:** a model with high **bias** underfits (too simple); one with high **variance** overfits (too sensitive to the training data).
- **Model evaluation for classification:** the **confusion matrix** (TP, FP, TN, FN).
  - Accuracy = (TP + TN) / total
  - Precision = TP / (TP + FP)
  - Recall (sensitivity) = TP / (TP + FN)
  - F1 score = 2 × precision × recall / (precision + recall)
- **For regression:** mean absolute error, mean squared error, root mean squared error, R².

## Module 3 — Similarity-based learning, regression and decision trees

> **In short:** **k-nearest neighbours (k-NN)** classifies a new point by looking at the k most similar training points. **Regression** fits a line or curve to predict a number; **logistic regression** predicts a probability for classification. A **decision tree** asks a series of questions about the features, choosing at each step the question that splits the data best.

```flow
New point -> Compute distance to every training point -> Pick the k nearest -> Majority vote (classification) or average (regression) -> Prediction
```

### Nearest-neighbour learning (k-NN)

k-NN is an **instance-based** (lazy) learner: it stores the training data and does the work only at prediction time.

1. Choose k (often odd, to avoid ties).
2. Compute the distance from the test point to every training point, usually the **Euclidean distance**: d = √Σ (xᵢ − yᵢ)².
3. Take the k closest points.
4. **Classification:** majority class among them. **Regression:** mean of their values.

Notes:

- **Scale the features** first, otherwise a feature with large values dominates the distance.
- **Small k** is sensitive to noise; **large k** blurs class boundaries.
- Prediction is slow for large data sets, because every distance is computed.

### Weighted k-NN

Closer neighbours get more say: each neighbour's vote is weighted, commonly by **1 / d** or 1 / d². This reduces the effect of distant neighbours and ties.

### Nearest centroid classifier

1. Compute the **centroid** (mean point) of each class from the training data.
2. Assign a new point to the class whose centroid is nearest.

It is fast and simple, but assumes each class forms a single compact group.

### Locally weighted regression (LWR)

Instead of one global model, LWR fits a **separate simple model (usually linear) near each query point**. Training points close to the query get large weights, often from a Gaussian kernel: w = exp(−d² / 2τ²), where τ (the bandwidth) controls how local the fit is.

### Introduction to regression

**Regression** models the relationship between a **dependent variable** y and one or more **independent variables** x, to predict y.

**Simple linear regression:** y = a₀ + a₁x. The **least squares** method chooses a₀ and a₁ to minimise the sum of squared errors Σ (yᵢ − ŷᵢ)²:

- a₁ = Σ (xᵢ − x̄)(yᵢ − ȳ) / Σ (xᵢ − x̄)²
- a₀ = ȳ − a₁x̄

**Worked example:** x = 1, 2, 3 and y = 2, 4, 5. x̄ = 2, ȳ = 11/3 ≈ 3.67. Numerator = (−1)(−1.67) + 0 + (1)(1.33) = 3.0; denominator = 1 + 0 + 1 = 2. So a₁ = 1.5 and a₀ = 3.67 − 3.0 = 0.67, giving y ≈ 0.67 + 1.5x.

**Assumptions:** linear relationship, independent errors, constant error variance (homoscedasticity), normally distributed errors, and (for multiple regression) no strong multicollinearity.

### Multiple and polynomial regression

- **Multiple linear regression:** y = a₀ + a₁x₁ + a₂x₂ + … + aₙxₙ. In matrix form, a = (XᵀX)⁻¹Xᵀy.
- **Polynomial regression:** y = a₀ + a₁x + a₂x² + … fits curves; it is still linear in the coefficients. A high degree overfits.

### Logistic regression

Used for **classification**, despite its name. It predicts the probability of class 1 with the **sigmoid** function:

p = 1 / (1 + e^(−z)), where z = a₀ + a₁x₁ + … + aₙxₙ

- The output is between 0 and 1; predict class 1 if p ≥ 0.5.
- **Log-odds (logit):** ln(p / (1 − p)) = z, which is linear in x.
- Coefficients are found by **maximum likelihood**, not least squares.

### Decision tree learning

A **decision tree** has:

- **internal nodes** that test an attribute
- **branches** for each outcome of the test
- **leaf nodes** that give the class

It is easy to read and turn into **if–then rules**, handles both categorical and numeric data, and needs little preparation. It can overfit, which **pruning** reduces.

**Building a tree (top-down, greedy):**

```flow
Start with all data at the root -> Pick the best attribute to split on -> Create a branch per value -> Repeat on each subset -> Stop when pure or no attributes left
```

### Decision tree induction algorithms

- **ID3** uses **information gain**:
  - Entropy(S) = −Σ pᵢ log₂ pᵢ (0 for a pure set; 1 for a 50/50 two-class set)
  - Gain(S, A) = Entropy(S) − Σ (|Sᵥ| / |S|) × Entropy(Sᵥ)
  - Split on the attribute with the **highest gain**.
- **C4.5** improves ID3: uses **gain ratio** (gain ÷ split information) to avoid favouring attributes with many values, handles numeric attributes and missing values, and prunes the tree.
- **CART** builds **binary** trees using the **Gini index**: Gini(S) = 1 − Σ pᵢ². Pick the split with the lowest weighted Gini. CART also does regression trees.

**Worked entropy example:** a set with 9 positive and 5 negative examples: Entropy = −(9/14) log₂(9/14) − (5/14) log₂(5/14) ≈ 0.940.

## Module 4 — Bayesian learning and artificial neural networks

> **In short:** **Bayesian learning** uses probability: it updates how likely each class is after seeing the evidence, using **Bayes' theorem**. **Naïve Bayes** assumes the features are independent given the class, which makes it fast and surprisingly accurate. **Artificial neural networks** are layers of simple units (neurons) whose connection weights are learned from data.

```flow
Prior P(class) -> Multiply by likelihood P(features | class) -> Normalise -> Posterior P(class | features) -> Pick the class with the highest posterior
```

### Probability-based learning

Probability-based learners combine **prior knowledge** with **observed data**. They give a probability for each answer, not just a label, and can be updated as new data arrives.

### Fundamentals of Bayes' theorem

**P(h | D) = P(D | h) × P(h) / P(D)**

- P(h) = **prior** probability of hypothesis h, before seeing data
- P(D | h) = **likelihood** of the data if h is true
- P(D) = probability of the data (the evidence)
- P(h | D) = **posterior** probability of h after seeing D

**MAP hypothesis** (maximum a posteriori): h_MAP = the h that maximises P(D | h) P(h). If all priors are equal, this becomes the **maximum likelihood (ML)** hypothesis, the h that maximises P(D | h).

**Bayes optimal classifier:** combines the predictions of all hypotheses, weighted by their posteriors. It is the best possible on average, but too costly in practice.

### Classification using the Bayes model: Naïve Bayes

To classify an instance with attributes a₁, a₂, …, aₙ:

**v_NB = the class v that maximises P(v) × P(a₁ | v) × P(a₂ | v) × … × P(aₙ | v)**

The "naïve" assumption: attributes are **conditionally independent** given the class.

Steps:

1. Compute the **prior** P(v) for each class from the training data.
2. For each attribute value, compute P(aᵢ | v) by counting.
3. Multiply for each class and pick the largest.

**Zero-probability problem:** if a value never occurs with a class, the whole product becomes 0. **Laplace correction** adds 1 to each count: P(aᵢ | v) = (count + 1) / (class count + number of possible values).

### Naïve Bayes for continuous attributes

For a numeric attribute, assume it follows a **normal (Gaussian) distribution** within each class. Estimate its mean μ and standard deviation σ per class, and use the Gaussian density:

P(x | v) = (1 / (σ√(2π))) × e^(−(x − μ)² / (2σ²))

### Artificial neural networks: biological and artificial neurons

- A **biological neuron** receives signals through **dendrites**, sums them in the **cell body (soma)**, and fires a signal along the **axon** to other neurons across **synapses** when the total passes a threshold.
- An **artificial neuron** computes a **weighted sum** of its inputs plus a **bias**, then applies an **activation function**: y = f(Σ wᵢxᵢ + b).

**Activation functions:**

| Function | Output |
|---|---|
| Step (threshold) | 1 if input ≥ threshold, else 0 |
| Sigmoid | 1 / (1 + e^(−x)), between 0 and 1 |
| Tanh | between −1 and 1 |
| ReLU | max(0, x) |
| Softmax | turns scores into probabilities that sum to 1 (output layer) |

### Perceptron and learning theory

The **perceptron** is a single neuron with a step activation, used for binary classification.

**Perceptron learning rule:** for each training example, wᵢ ← wᵢ + η (t − o) xᵢ, where t is the target, o the output and η the learning rate.

```flow
Initialise weights -> Compute output for an example -> Compare with target -> Update weights by the error -> Repeat until no errors (or max epochs)
```

- It converges if the classes are **linearly separable**.
- A single perceptron cannot learn **XOR**, which is not linearly separable. This needs a hidden layer.

### Types of artificial neural networks

- **Feed-forward networks:** signals move one way, input → hidden → output. A **multi-layer perceptron (MLP)** has one or more hidden layers.
- **Backpropagation:** trains an MLP. The error at the output is propagated backwards, and each weight is adjusted by **gradient descent** to reduce the error.
- **Fully connected networks**, **recurrent neural networks (RNN)** with feedback loops for sequences, **convolutional neural networks (CNN)** for images, **radial basis function** networks, **self-organising maps** (unsupervised).

### Applications, advantages, disadvantages and challenges of ANN

- **Applications:** image and speech recognition, handwriting recognition, machine translation, medical diagnosis, forecasting, game playing.
- **Advantages:** learns complex non-linear relationships; works with noisy data; learns from examples without explicit rules; can run in parallel.
- **Disadvantages:** needs lots of data and computing power; works as a "black box" that is hard to explain; can overfit; choosing the architecture is trial and error.
- **Challenges:** training time, choosing hyper-parameters (layers, neurons, learning rate), vanishing gradients in deep networks, and needing large labelled data sets.

## Module 5 — Clustering and reinforcement learning

> **In short:** **clustering** groups similar items without labels. **Hierarchical** methods build a tree of clusters; **partitional** methods such as **k-means** split the data into k groups; **density-based** methods (DBSCAN) find dense regions of any shape. **Reinforcement learning** trains an agent to choose actions that maximise long-term reward, for example with **Q-learning**.

```flow
k-means: Choose k -> Pick k initial centroids -> Assign each point to the nearest centroid -> Recompute centroids -> Repeat until assignments stop changing
Reinforcement learning: Agent observes state -> Takes action -> Environment gives reward and next state -> Agent updates its policy -> Repeat
```

### Introduction to clustering approaches

**Clustering** puts similar objects in the same group (high intra-cluster similarity) and different objects in different groups (low inter-cluster similarity).

Applications: customer segmentation, document grouping, image segmentation, anomaly detection, gene analysis.

Approaches: **hierarchical**, **partitional**, **density-based**, **grid-based**, and model-based.

### Proximity measures

**Distance between numeric points x and y:**

- **Euclidean:** √Σ (xᵢ − yᵢ)²
- **Manhattan (city block):** Σ |xᵢ − yᵢ|
- **Minkowski:** (Σ |xᵢ − yᵢ|ᵖ)^(1/p); p = 1 gives Manhattan, p = 2 gives Euclidean
- **Chebyshev:** max |xᵢ − yᵢ|

**For binary data:** simple matching coefficient, **Jaccard coefficient** (ignores 0–0 matches), Hamming distance.

**For text or vectors:** **cosine similarity** = (x · y) / (|x| |y|).

### Hierarchical clustering algorithms

Build a tree of clusters (a **dendrogram**); cutting the tree at a level gives the clusters.

- **Agglomerative (bottom-up):** start with each point as its own cluster and repeatedly merge the two closest clusters.
- **Divisive (top-down):** start with one cluster and repeatedly split.

**Distance between clusters (linkage):**

| Linkage | Distance between two clusters |
|---|---|
| Single | Closest pair of points (can form long chains) |
| Complete | Farthest pair of points (compact clusters) |
| Average | Average over all pairs |
| Centroid / mean | Distance between the centroids |

### Partitional clustering: k-means

1. Choose the number of clusters k.
2. Choose k initial centroids (randomly, or with **k-means++**).
3. Assign each point to its **nearest centroid**.
4. Recompute each centroid as the **mean** of its points.
5. Repeat steps 3–4 until the assignments no longer change.

k-means minimises the **sum of squared errors (SSE)**: the sum of squared distances from each point to its centroid.

- **Strengths:** simple and fast, O(n k t) for n points and t iterations.
- **Weaknesses:** k must be chosen in advance (the **elbow method** helps); sensitive to initial centroids and outliers; finds only roughly spherical clusters.
- **k-medoids (PAM):** uses actual data points as cluster centres, so it is less sensitive to outliers.

### Density-based methods: DBSCAN

DBSCAN groups points that are densely packed. It has two parameters: **ε** (neighbourhood radius) and **MinPts** (minimum points in a neighbourhood).

- **Core point:** has at least MinPts points within ε.
- **Border point:** within ε of a core point but not a core point itself.
- **Noise point:** neither; treated as an outlier.

Clusters grow from core points through **density-reachable** points. DBSCAN finds clusters of **any shape** and does not need k, but it struggles when clusters have very different densities.

### Grid-based approach

Divide the data space into a finite number of **cells (a grid)** and cluster the dense cells, rather than the points. It is fast, because the cost depends on the number of cells, not the number of points. Examples: **STING** and **CLIQUE** (which also finds clusters in subspaces).

### Overview and scope of reinforcement learning

In **reinforcement learning (RL)**, an **agent** learns by trial and error. There is no labelled answer, only a **reward** signal, which may be **delayed**. The agent must balance **exploration** (trying new actions) and **exploitation** (using what it knows works).

Scope: game playing (chess, Go), robotics, self-driving vehicles, resource management, recommendation systems.

### RL as machine learning, and its components

RL differs from supervised learning (no correct answer is given for each step) and from unsupervised learning (there is a goal: maximise reward).

**Components:**

- **Agent:** the learner and decision-maker.
- **Environment:** everything the agent interacts with.
- **State (s):** the current situation.
- **Action (a):** what the agent can do.
- **Reward (r):** the immediate feedback.
- **Policy (π):** the agent's rule for choosing an action in each state.
- **Value function:** the expected long-term reward from a state (V) or from a state–action pair (Q).
- **Model** (optional): the agent's knowledge of how the environment behaves.

### Markov decision process (MDP)

An MDP formalises RL as (S, A, P, R, γ):

- S: the set of states; A: the set of actions
- P(s′ | s, a): the probability of moving to s′ after action a in state s
- R: the reward function
- **γ (discount factor, 0 ≤ γ ≤ 1):** how much future rewards count. The **return** is G = r₁ + γ r₂ + γ² r₃ + …

The **Markov property:** the next state depends only on the current state and action, not on the earlier history.

### Multi-arm bandit problem and problem types

The **multi-arm bandit** has one state and several actions ("slot machine arms"), each with an unknown reward distribution. The agent must find the best arm while still earning reward: the exploration–exploitation dilemma in its simplest form.

**ε-greedy strategy:** with probability ε choose a random arm (explore), otherwise choose the best-known arm (exploit).

**Problem types:** episodic versus continuing tasks; deterministic versus stochastic environments; fully versus partially observable states.

### Model-based and model-free methods

- **Model-based learning:** the agent knows (or learns) P and R, and plans with **dynamic programming**: **policy evaluation**, **policy iteration** and **value iteration**, using the **Bellman equation**.
- **Model-free methods:** learn directly from experience without a model.
  - **Monte Carlo** methods learn from complete episodes.
  - **Temporal difference (TD)** methods update after every step, using the estimate of the next state.

### Q-learning

An **off-policy** TD method. It learns Q(s, a), the value of taking action a in state s and then acting optimally:

**Q(s, a) ← Q(s, a) + α [r + γ max over a′ of Q(s′, a′) − Q(s, a)]**

- α is the learning rate; the term in brackets is the **TD error**.
- It uses the **best** next action in its update, whatever action the agent actually takes next.

### SARSA learning

An **on-policy** TD method, named after the tuple (**S**tate, **A**ction, **R**eward, next **S**tate, next **A**ction):

**Q(s, a) ← Q(s, a) + α [r + γ Q(s′, a′) − Q(s, a)]**

- It uses the action a′ that the agent **actually** takes next (for example, from its ε-greedy policy).
- SARSA tends to learn safer behaviour during exploration; Q-learning learns the optimal policy more directly.

## Exam tips

- **Numericals are common:** mean, median, variance and standard deviation; correlation; a linear regression line; entropy and information gain for a decision tree; Naïve Bayes for a small table; k-NN distances; one or two k-means iterations.
- Draw and label the **perceptron**, an **MLP**, the **confusion matrix**, a **dendrogram** and the **RL agent–environment loop**.
- **Compare** pairs: supervised vs unsupervised, classification vs regression, ID3 vs C4.5 vs CART, k-means vs DBSCAN, Q-learning vs SARSA, filter vs wrapper feature selection.
- Know **Find-S** and **Candidate Elimination** traces for a small training set.
- State the **Bayes' theorem** formula and the Q-learning update rule exactly; marks are given for the formula.
