For the VTUHub.site prompt, use this visual design system. It is optimized for a fast, clean academic resource/file-store experience, not a generic education template.

Visual Design System

Design VTUHub.site as a premium, minimal, high-performance academic resource platform.

The visual language should combine:

- Modern file/resource management
- Clean documentation websites
- Academic portals
- Search-first interfaces

Do not make it look like a typical college website.

1. Design principles

Follow these principles:

- Content first
- Search first
- Extremely clean
- High information density without clutter
- Strong typography
- Clear hierarchy
- Minimal decoration
- Fast visual rendering
- Mobile-first
- Accessibility-first

Avoid:

- Excessive gradients
- Glassmorphism
- Huge hero sections
- Excessive rounded cards
- Heavy shadows
- Unnecessary animations
- Decorative illustrations that don't provide value
- Excessive colors

2. Color system

Use a restrained neutral-based palette.

Use the primary accent sparingly.

Support dark mode with:

3. Typography

Use a highly readable modern sans-serif.

Prefer:

Inter

Use:

Body:       15–16px
Small:      13–14px
Caption:    12–13px
H1:         36–48px
H2:         28–32px
H3:         20–24px

On mobile:

H1: 30–36px
H2: 24–28px
H3: 18–22px

Use medium/semibold weights for headings.

Avoid excessively bold typography.

5. Header

Create a compact, professional header.

Desktop:

[ VTUHub ]  Browse  Resources  Tools  Updates     Search

Keep the header approximately 64px high.

Use a subtle bottom border.

Do not use a large header.

Mobile:

[ VTUHub ]                         [Menu]

The search should remain easily accessible.

This is the most important visual component.

Prefer a clean file-list interface rather than large cards.

📄  Unit 3 Notes                  PDF   2.1 MB   Download
📄  Unit 4 Notes                  PDF   2.7 MB   Download

On desktop:

File                     Type       Size       Updated       Action
------------------------------------------------------------------
DBMS Unit 1 Notes        PDF        2.4 MB     Sep 2026      Download

On mobile, convert each row into a compact responsive layout.

8. Breadcrumbs

Use breadcrumbs heavily.

Example:

Home / CSE / 3rd Semester / DBMS / Notes

Breadcrumbs should be small, muted, and unobtrusive.

They should also support SEO structured data.

9. Subject page

Use:

DBMS
Database Management Systems

CSE · 3rd Semester · 2022 Scheme

Then show resources in a clean list.

Do not put every resource inside a huge card.

10. Cards

Use cards selectively.

Cards are appropriate for:

- Branches
- Semesters
- Tools
- Featured resources

Cards should have:

border: 1px solid
border-radius: 10–12px
minimal/no shadow

Avoid floating-card-heavy layouts.

11. Buttons

Primary button:

Solid accent background
White text
Medium weight
8px radius

Secondary:

Transparent/white
Border
Dark text

Ghost:

No border
Subtle hover background

Download buttons should be visually obvious but not oversized.

13. Filters

Use compact filter controls:

Branch     Semester     Scheme     Type
[CSE ▼]    [3 ▼]        [2022 ▼]   [Notes ▼]

On mobile, convert them into a filter drawer/sheet.

14. Icons

Use a lightweight icon system.

Icons should be:

- Simple
- Consistent
- 16–20px
- Mostly outline style

Use icons for:

- Files
- Search
- Download
- External links
- Branches
- Subjects
- Tools
- Navigation

Do not use icons as decoration everywhere.

15. Ad placement

Advertising must visually integrate without confusing users.

Ads should have:

Advertisement

with subtle separation from content.

Never make an ad look like:

- A download button
- A resource
- A navigation item
- An official VTU notification

Reserve ad space to prevent layout shift.

17. Responsive behavior

Desktop:

Wide content
Optional sidebar
Horizontal filters
File tables

Tablet:

Reduced spacing
Responsive grids
Compact navigation

Mobile:

Single-column
Bottom/side navigation where appropriate
Full-width search
Stacked filters
Compact file rows
Touch-friendly buttons

Minimum touch target:

44px

18. Animations

Use very little animation.

Allowed:

- Button hover
- Dropdown transition
- Mobile drawer
- Search result appearance

Duration:

100–200ms

Avoid:

- Parallax
- Large entrance animations
- Continuous animations
- Animated backgrounds
- Heavy page transitions

Respect:

prefers-reduced-motion

19. Accessibility

Use:

- Semantic HTML
- Proper heading hierarchy
- Keyboard navigation
- Visible focus states
- ARIA only where necessary
- Sufficient color contrast
- Accessible form labels
- Accessible download controls

20. Performance rule

The visual system must never compromise performance.

Prefer:

CSS
HTML
SVG
Astro components

Avoid unnecessary:

JavaScript
Web fonts
Large images
Animation libraries
UI frameworks

The final visual result should feel like:

A very fast, polished academic Google Drive/documentation-style resource platform — but with an original VTUHub identity.

The interface should make finding and downloading VTU resources the easiest possible action.
