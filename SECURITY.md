# Security policy

VTUHub is a static website: there are no accounts, logins, databases or server code.

If you find a security problem (for example a script injection through the search,
a broken redirect, or a leaked key in the repository), please **do not open a public
issue**. Email **vtuhub2021@gmail.com** with the details and steps to reproduce.
You will get a reply within a few days.
