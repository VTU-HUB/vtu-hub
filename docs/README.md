# VTUHub documentation

VTUHub ([vtuhub.site](https://vtuhub.site)) is a free, open-source study site for
VTU students: every programme, semester and subject on the 2022 scheme, with the
official syllabus, module-wise notes, PDFs, calculators and VTU notices.

| Guide | For |
|---|---|
| [Writing notes](writing-notes.md) | Anyone who wants to write or fix study notes |
| [Architecture](architecture.md) | How the site is built: pages, data, PDFs, search |
| [Data pipeline](data-pipeline.md) | How course, syllabus and notice data is synced from vtu.ac.in |
| [Features](features.md) | What each student-facing feature does and where its code is |
| [Deployment](deployment.md) | Build, hosting, SEO and analytics |
